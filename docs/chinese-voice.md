# 中文写作标准

本站每段文字都有中英两版。**中文不是英文的译文，是同一件事的中文原文。**

这份文档是 D66 裁决第六节的执行标准。改写时对照这里的样例，不要对照英文句子逐节转写。

## 方法

1. **先读懂，再重说。** 读完英文那句，合上，用中文把这件事说一遍。写完再回头核对：
   有没有说漏、有没有说多、有没有说反。只对这三件事负责，不对句子结构负责。
2. **拆长句。** 英文一个从句套从句的长句，中文写成两三个短句。中文靠句子的先后顺序
   表达逻辑，不靠一个长定语堆在「的」前面。
3. **中英不必逐句对应。** 允许中文合并两句、拆成三句、调换先后。只要说的是同一件事就行。
   不要为了对齐而牺牲中文。

## 技术词

- 社区已通用的英文词**保留英文**：truthiness、prop、hook、diff、eject、bundle、
  source map。必要时在括号里解释它是什么，不要生造中译。
- 已有稳定中译的用中译：编译器、运行时、字面量、断言、诊断、门禁、样式表。
- 第一次出现的自造概念，给一句解释，别指望读者从字面猜。

## 禁止清单

出现即改。这些是站内实际出现过的问题写法。

| 禁止 | 因为 | 改成 |
| --- | --- | --- |
| 书写表面 | writing surface 逐字直译，不是中文词 | 写起来像…… / 看得见的那一面 |
| 真值性 | truthiness 的生造对译 | truthiness（空字符串和 0 不会被当成 false） |
| 无主的 promise 失败 | unowned 直译 | 没人管的 promise 失败 |
| 报告身份 | reports an identity 直译 | 只说「是哪一个」 |
| 弹出（指 eject） | eject 直译，中文里是别的意思 | 带着产物离开 / eject |
| 正是……的原因 | 英文分裂句直译 | 把因果拆成两个短句 |
| ……的事实 / ……这一点（作主语） | 英文名词化直译 | 直接说那件事 |
| 承载 / 之上 / 就此而言 | 翻译腔 | 说人话 |

## 改写样例

左边全部是站内原文，右边是标准。

**开场定义**

> 原：一门编译到 JavaScript 的应用语言：以 Python 的书写表面，承载 JavaScript 的运行时语义。语言核心独立成立，Web 是项目按需激活的官方扩展。

> 改：写起来是 Python，跑起来是 JavaScript。语言核心自己就能立住；Web 是官方扩展，项目要用的时候才激活。

**使命**

> 原：它为「模型书写、人来拥有」的代码而设计：读者必须能够核验代码在做什么，而当编译器无法确认时，它必须说出来。

> 改：它面向这样一种代码——模型来写，人来负责。所以读的人必须能核对代码到底在做什么；而编译器自己拿不准的时候，必须说出来。

**语言性质**

> 原：同一门源语言，以缩进结构的 Python 形态书写，以普通 JavaScript 运行。VelarScript 建立在 JavaScript 与 Python 的骨架之上——这是每个模型都最熟悉的两门语言。程序活在并运行于 JavaScript 之中，因此行为以它为准。

> 改：一门语言，写的时候是 Python 那样的缩进结构，跑起来就是普通 JavaScript。这两门语言是所有模型最熟的，VelarScript 就搭在它们的骨架上。程序真正运行的地方是 JavaScript，所以行为一律以 JavaScript 为准。

**移除陷阱**

> 原：这里没有隐式强制转换、没有真值性、没有被静默丢弃的语句，也没有无主的 promise 失败。

> 改：没有隐式类型转换，没有 truthiness（空字符串和 0 不会被当成 false），没有被悄悄丢掉的语句，也没有没人管的 promise 失败。

**为什么统一**

> 原：统一的输出，正是让一份代码库能被并非其作者的人维护的原因——包括下一次会话，或下一个模型。

> 改：输出统一，别人才接得住这份代码。「别人」也包括下一次会话、下一个模型。

**prop 只读**

> 原：因此子组件报告身份、由拥有者执行改动——这正是上面那一行传的是 id、而不是直接改动收到的 task 的原因。

> 改：子组件只说「是哪一个」，真正的改动由数据的拥有者来做。上面那一行传的是 id，而不是直接改收到的 task，就是这个道理。

**警告即失败**

> 原：因此警告是一次失败，而不是一种习惯。

> 改：所以警告就是失败，不会变成一件「大家都习惯了」的事。

**逃生通道**

> 原：代价是弹出是单向的——从那以后由你维护那份 JavaScript——而这恰恰使它成为一个诚实的出口而不是一句承诺。

> 改：代价是这道门只能出、不能回：走出去之后，那份 JavaScript 就归你维护了。也正因为如此，它才是一个真的出口，而不是一句承诺。

## 验收

随机抽 30 段中文，**遮住英文读**。读起来像中文技术文档就过，像译文就不过。

这条无法自动化，由人裁定。自动化能做的只有禁止清单：那部分应当进门禁。
